Lichess Puzzle Bot

Running

Posts the Lichess daily puzzle to Slack every day, checks thread replies against the solution, and keeps a running leaderboard of who's solving them.

How it works

1

The daily puzzle is posted to the channel as a new thread, with the position shown as an image.

2

Reply in that thread with the full line, e.g. Nf3 Nc6 Bb5 - your moves and your opponent's forced replies, in order.

3

You get a DM with the result. Run /leaderboard anywhere in the workspace to see current standings.
